# 自主决策记录（初稿）

1. **运行目录 = 启动时工作目录**，不是 jar 所在目录。理由：符合 `java -jar` 直觉，且满足"移动 jar 重新初始化"；避免写 jar 同目录可能无权限。
2. **配置放 `./config/application.yml`**：Spring Boot 默认加载该位置；首次运行由 bootstrap 生成并带注释，存在则不覆盖。
3. **默认端口 8080**：避开保留端口、常见易改；启动日志打印实际端口，兼容改为 0 随机端口。
4. **H2 单文件库 `./data/db/greydrive`**：零安装；`ddl-auto=validate` 让 Flyway 唯一管理结构。
5. **内容寻址 + blob 引用计数**：sha256 同时服务秒传与去重；ref_count 避免误删被共享引用的内容。
6. **分片独立目录 `chunks/<uploadId>/`**：与正式存储隔离，取消/过期直接删目录；合并先写 `tmp/` 再原子移动。
7. **分片默认 8 MiB**：移动网络友好，2 GiB 约 256 片，可控。
8. **上传会话 24h + 每 10 分钟清理**：兼顾续传与磁盘回收。
9. **JWT HS256 + 32 字节密钥文件**：无状态、无需 Redis；密钥损坏快速失败而非静默重建。
10. **密码 BCrypt strength 12**：Spring Security 自带、纯 Java、自带盐。
11. **分享 token 22 字符 URL-safe 随机，提取码 6 位**：提取码存 BCrypt；校验通过签发 30 分钟分享 JWT，避免每请求 BCrypt。
12. **越权统一资源不存在错误**（`10004`/`12001`/`12002`）：不区分"不存在"与"无权限"，防资源探测。
13. **文件名不参与磁盘路径**：磁盘键仅用 sha256 十六进制，杜绝路径穿越；文件名经 Content-Disposition 安全编码输出。
14. **版本回滚 = 新增版本**：历史可追溯，复用同一 blob 不增加物理占用。
15. **搜索用 SQL LIKE + 组合过滤**：单机规模足够；不引 Elasticsearch（破坏单 jar）。
16. **缩略图 Thumbnailator 按需生成并落盘缓存**：纯 Java 无 native；Caffeine 只缓存元信息。
17. **操作日志异步写**：主流程不受影响；有界线程池，满则丢弃并告警，不阻塞业务。
18. **Logback 按大小+时间滚动**（50MB/30 天/1GB）：只记录必要字段，不打印密码、JWT、提取码、文件内容。
19. **测试用独立 H2 内存库 + 临时数据目录**：不污染工作目录，Flyway 每个上下文真实执行；每模块一个集成测试类。
20. **不启用 Security 会话/CSRF/表单登录**：仅保留无状态过滤器链，减少攻击面。
21. **分享默认永不过期**（`expires_at` 可空），创建时仍可指定秒数；满足"无限"需求，同时保留可配置能力。
22. **Web 后台用原生 HTML/CSS/JS 单页应用**，由 Spring Boot 托管静态资源：不引入 Node 构建链，保持"一个 jar"；页面与 API 同源，无跨域配置。
23. **服务 8080 + 管理后台 80 双端口**（已变更）：现统一为 20020 单端口，独立管理端口默认关闭。
24. **登录强制 TOTP 二次验证**（`mfa-required=true`）：未绑定用户先用短时 `mfaToken` 完成绑定；已绑定用户走验证码/恢复码。恢复码只存 BCrypt，避免认证器丢失后锁死账号。
25. **TOTP 与二维码用纯 Java 实现**（HMAC-SHA1 自实现 + ZXing）：不引入外部认证服务，保持离线单 jar。
