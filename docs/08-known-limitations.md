# 已知限制

1. **单实例**：不支持多实例横向扩展；H2 文件锁与本地磁盘决定了同一数据目录只能一个进程。
2. **存储上限**：受单机磁盘与文件系统限制；默认单文件上限 2 GiB，可配置。
3. **性能边界**：带宽与磁盘 IO 为单机上限；大文件合并会短暂占用约两倍磁盘空间（分片 + 合并临时文件）。
4. **搜索**：SQL `LIKE` 实现，适合个人/小团队规模；大规模全文检索需外部搜索引擎，当前不引入。
5. **对象存储**：`StorageService` 已抽象，但当前只有本地磁盘实现；S3/MinIO/OSS 仅为未来扩展点，未实现。
6. **预览**：缩略图仅支持常见位图格式；不做视频转码、PDF 渲染、Office 文档解析。
7. **文本预览**：按字节截断，超过上限会标记 `truncated`；非 UTF-8 文本可能显示乱码。
8. **无配额**：未实现单用户容量配额与带宽限速。
9. **安全边界**：未内置 TLS、登录失败锁定、IP 白名单；应由反向代理/网关补充（TOTP 二次验证已内置）。
10. **令牌撤销**：JWT 无状态，改密后旧令牌在过期前仍有效；需要立即失效只能轮换 `jwt.secret`。
11. **多用户隔离**：逻辑隔离（`user_id`），物理文件按内容寻址共享；同一内容不同用户只存一份。
12. **无移动/桌面客户端**：提供浏览器 Web 后台（SPA）与 HTTP API/Swagger，不含原生客户端。
13. **备份**：H2 运行中直接复制可能不一致，推荐停服备份。
14. **时区**：数据库时间统一 UTC，API 返回 ISO-8601。
15. **独立管理端口 80**：默认关闭（`greydrive.admin.enabled=false`），服务、API 与管理后台统一走 20020。如启用，需要 root 或 `cap_net_bind_service`；不可用时自动跳过，不影响 20020。
16. **前端形态**：后台是静态资源 SPA（HTML/CSS/JS），数据全部来自动态 API；不提供 SSR。
17. **MFA 边界**：仅支持 TOTP，不含短信/邮件验证码、WebAuthn；恢复码需用户自行离线保存，全部丢失且认证器不可用需管理员在数据库重置。
18. **浏览器兼容**：依赖 `crypto.subtle`（SHA-256 秒传）与 `fetch`，不支持 IE。
