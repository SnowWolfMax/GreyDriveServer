# 安全说明

## 1. JWT 密钥持久化

- 首次启动生成 32 字节随机密钥，Base64 写入 `data/secrets/jwt.key`，POSIX 权限 `600`。
- 后续启动读取同一文件，令牌跨重启有效。
- 文件存在但长度不足时直接启动失败，不会静默换密钥（避免所有用户被强制登出）。
- 备份数据时必须同时备份该文件；泄露该文件等于可以伪造任意用户令牌，应严格限制读权限。

## 2. 密码存储

- 使用 BCrypt（cost 12）加盐哈希，数据库中不保存明文。
- 登录失败统一返回 `11002 用户名或密码错误`，不区分用户是否存在。
- 密码长度限制 8-72（BCrypt 输入上限）。

## 3. 分享安全

- 分享 token 为 16 字节安全随机数的 URL-safe Base64（22 字符），不可枚举。
- 提取码只保存 BCrypt 哈希，创建接口仅在响应中返回一次明文。
- 提取码校验通过后签发 30 分钟分享访问 JWT（`X-Share-Token`），避免每次请求做哈希计算。
- 提取码校验按 `token + IP` 限速：5 分钟内最多 5 次失败，超过返回 `10009`。
- 服务端每次访问都会校验分享状态与有效期；取消或过期立即失效。
- 权限分 `VIEW`（预览/缩略图/目录列表）与 `DOWNLOAD`（原文件下载）；越权返回 `14004`。

## 4. 路径穿越防护

- 磁盘路径只由 SHA-256 十六进制构造：`storage/blobs/<aa>/<bb>/<sha256>`，用户输入不参与路径拼接。
- 本地存储实现额外校验解析后的路径必须位于存储根目录内。
- 文件名仅存数据库；输出时做安全编码（`Content-Disposition` 同时提供 ASCII 回退与 `filename*`）。
- 目录/文件名拒绝 `/`、`\`、`.`、`..`。

## 5. 越权访问

- 所有文件、目录、标签、分享、日志查询都强制带当前 `user_id`。
- 非本人资源与不存在资源统一返回 `10004 资源不存在或无权访问` / `12002 文件不存在`，不泄露资源是否存在。
- 分享访问校验目标文件是否位于分享目录子树内。

## 6. 传输与部署

- 服务默认只提供 HTTP；公网部署必须由反向代理提供 HTTPS。
- 默认监听 `0.0.0.0`，请通过防火墙限制来源，或改为内网地址。
- H2 控制台未启用。
- Swagger 默认公开；如需关闭，可在 `application.yml` 中关闭 springdoc（`springdoc.api-docs.enabled=false`、`springdoc.swagger-ui.enabled=false`）。

## 7. 日志脱敏

- 操作日志只记录动作、资源 id、结果、IP、User-Agent。
- 不记录密码、JWT、分享提取码、文件内容。
- 异常日志会记录堆栈用于排查，但请求体不写入日志。

## 8. 二次验证（TOTP）

- 默认 `greydrive.security.mfa-required=true`：新用户首次登录必须绑定 TOTP 才能进入系统。
- TOTP 遵循 RFC 6238：HMAC-SHA1、30 秒步长、6 位，校验允许前后各一个时间窗。
- 密钥为 20 字节随机数（Base32 存储），二维码由服务端用 ZXing 生成，不依赖外部服务。
- 绑定成功后生成 10 个一次性恢复码，仅存 BCrypt 哈希；使用后标记失效。
- 登录密码校验通过后先返回 5 分钟有效的 `mfaToken` 挑战令牌，验证通过才签发正式 JWT。
- 修改密码后旧 JWT 在过期前仍有效；如需立即失效，轮换 `jwt.key`。
- 恢复码用完后可在设置页重新生成（需当前 TOTP）。

## 9. 其他约定

- 密码修改后，已签发令牌在过期前仍有效（无状态 JWT 的取舍）。如需立即失效，可轮换 `jwt.key` 使全部令牌失效。
- 未实现登录失败次数锁定、IP 白名单；这些应由反向代理或网关补充。
- 单机部署默认信任本机磁盘安全；请确保运行用户对 `data/` 有独占权限。
